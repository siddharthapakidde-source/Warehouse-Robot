# Warehouse Automation Robot

## 📌 Overview
This project is an autonomous warehouse automation robot designed to navigate inside a warehouse, detect racks, 
and perform material transport operations with minimal human intervention.

## Features
- Line following using IR sensors  
- Rack detection using ultrasonic sensor  
- Autonomous navigation logic  
- WiFi-enabled control using ESP32  
- Motor control using L298N driver  

## Working Principle
The robot follows a predefined path using IR sensors.  
When a rack is detected at a specific distance using an ultrasonic sensor, the robot stops and performs the required operation.  
WiFi connectivity enables monitoring and future cloud integration.

## Hardware Used
- ESP32  
- IR Sensors  
- Ultrasonic Sensor  
- L298N Motor Driver  
- DC Motors  
- Power Supply  

##  Software Used
- Arduino IDE  
- Embedded C / C++
